1. Introduction à l'algorithmique

L'algorithmique est l'étude et la conception d'algorithmes - des procédures étape par étape pour résoudre un problème.

2. Concepts fondamentaux

Variables et types de données

5. Tableaux

Un tableau est une collection ordonnée d'éléments.

// Déclaration d'un tableau

// Accès aux éléments (index commence à 0)
console.log(fruits[0]);  // pomme
console.log(fruits.length);  // 3

// Ajouter un élément
fruits.push("raisin");

// Parcourir le tableau
for (let i = 0; i < fruits.length; i++) {
    console.log(fruits[i]);
}

6. Complexité algorithmique

Complexité O(n) : Le temps augmente linéairement avec la taille de l'entrée. Exemple : parcourir un tableau.
Complexité O(n²) : Le temps augmente au carré. Exemple : boucles imbriquées.
Complexité O(log n) : Le temps augmente logarithmiquement. Exemple : recherche binaire.

Exercice 2 : Calculer la somme d'un tableau

Écrivez une fonction qui retourne la somme de tous les éléments d'un tableau.

Solution : 
function sommeTableau(tableau) {
    let somme = 0;
    for (let i = 0; i < tableau.length; i++) {
        somme += tableau[i];
    }
    return somme;
}

// Utilisation
let nombres = [1, 2, 3, 4, 5];
console.log(sommeTableau(nombres));  // 15

Exercice 3 : Trouver le maximum d'un tableau

Écrivez une fonction qui retourne le plus grand nombre d'un tableau.

Solution : 
function trouverMax(tableau) {
    let max = tableau[0];
    for (let i = 1; i < tableau.length; i++) {
        if (tableau[i] > max) {
            max = tableau[i];
        }
    }
    return max;
}

// Utilisation
console.log(trouverMax([3, 7, 2, 9, 1]));  // 9
