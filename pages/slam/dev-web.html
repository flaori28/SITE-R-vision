HTML5 Sémantique

HTML5 introduit des balises sémantiques qui donnent du sens au contenu.

<header> : En-tête de page avec logo, titre principal, navigation principale.
<nav> : Bloc de navigation (menus, liens de section).
<main> : Contenu principal de la page (une seule par page).
<article> : Contenu autonome réutilisable (blog post, news, commentaire).
<section> : Groupe thématique de contenu avec un titre.
<aside> : Contenu périphérique (sidebar, publicités, informations liées).
<footer> : Pied de page avec copyright, liens, informations légales.
Exemple structure HTML5 :
<!DOCTYPE html> <html lang="fr"> <head><title>Mon Site</title></head> <body> <header><h1>Mon Blog</h1></header> <nav><ul><li><a href="#">Accueil</a></li></ul></nav> <main> <article><h2>Article 1</h2><p>Contenu...</p></article> <aside><h3>Sidebar</h3></aside> </main> <footer><p>© 2024</p></footer> </body></html>

CSS3 : Flexbox et Grid

Flexbox (Flexible Box Layout)

Modèle de disposition 1D pour aligner items en rangée ou colonne.

.container { display: flex; flex-direction: row; /* ou column */ justify-content: space-between; /* Align horizontal */ align-items: center; /* Align vertical */ gap: 20px; /* Espace entre items */ } .item { flex: 1; /* Croissance égale */ }

CSS Grid

Modèle 2D pour créer des grilles complexes.

.grid { display: grid; grid-template-columns: repeat(3, 1fr); grid-gap: 20px; grid-template-rows: auto 1fr auto; }

Media Queries (Responsive)

/* Desktop */ .container { display: flex; flex-direction: row; } /* Tablette */ @media (max-width: 768px) { .container { flex-direction: column; } } /* Mobile */ @media (max-width: 480px) { .container { padding: 10px; } }

PHP : Traitement Serveur

Formulaires (GET et POST)

/* HTML */ <form method="POST" action="process.php"> <input name="email" type="email"> <button type="submit">Envoyer</button> </form> /* PHP */ if ($_SERVER['REQUEST_METHOD'] === 'POST') { $email = $_POST['email']; echo "Email reçu: " . htmlspecialchars($email); }

Sessions

/* Démarrer session */ session_start(); /* Stocker données */ $_SESSION['user_id'] = 123; $_SESSION['username'] = 'Jean'; /* Récupérer données */ echo $_SESSION['username']; /* Détruire session */ session_destroy();

Connexion PDO à BD

Exercice 4 : Script PHP Traitement Formulaire
Écrivez un script PHP qui traite un formulaire POST et insère les données (nom, email) dans une BD MySQL via PDO.
<?php $db = new PDO('mysql:host=localhost;dbname=mydb', 'user', 'password'); if ($_SERVER['REQUEST_METHOD'] === 'POST') { $name = htmlspecialchars($_POST['name']); $email = htmlspecialchars($_POST['email']); $stmt = $db->prepare('INSERT INTO users (name, email) VALUES (?, ?)'); $stmt->execute([$name, $email]); echo 'Utilisateur créé!'; } ?>
