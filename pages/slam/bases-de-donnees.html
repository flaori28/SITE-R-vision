1. Modèle Conceptuel de Données (MCD)

📚 Définition

MCD = représentation graphique des données et de leurs relations

Il permet de modéliser la structure logique d'une base de données avant sa création.

Composants principaux :

  • Entité : Un objet ou concept
  • Attribut : Une propriété d'une entité
  • Association : Un lien entre entités
  • Cardinalité : Le nombre de relations (0..1, 1..1, 0..N, 1..N)
Exemple de MCD : Client (Num_Client, Nom, Prénom, Email) Commande (Num_Commande, Date_Commande, Montant) Relation : Client ------- Passer -----→ Commande Cardinalité: 1..N 1..1

2. Transformation MCD → MLD

📚 Modèle Logique de Données (MLD)

Transformation du MCD en tables relationnelles

Règles de transformation :

Règle 1 : Toute entité devient une table Règle 2 : Tout attribut devient une colonne Règle 3 : Tout identifiant devient une clé primaire (PK) Règle 4 : Pour association 1..N : clé étrangère dans la table côté N Règle 5 : Pour association N..N : créer une table d'association

3. SQL Fondamental

📚 SELECT - Récupérer des données

SELECT colonne1, colonne2 FROM table WHERE condition; SELECT * FROM Clients; SELECT Nom, Email FROM Clients WHERE Ville = 'Paris'; SELECT COUNT(*) FROM Commandes;

4. Intégrité Référentielle

📚 Clés Étrangères (FK)

Maintiennent la cohérence entre les tables

CREATE TABLE Commande ( Num_Commande INT PRIMARY KEY, Num_Client INT, FOREIGN KEY (Num_Client) REFERENCES Client(Num_Client) );

Exercices Pratiques

Exercice 1 : Créer un MCD

Énoncé : Créer le MCD pour une bibliothèque avec Livres, Auteurs et Emprunts

Solution :
Livres (ISBN, Titre, Année_Publication) Auteurs (Num_Auteur, Nom, Prénom) Emprunts (Num_Emprunt, Date_Emprunt, Date_Retour) Relation : Auteurs ------- Écrire -------→ Livres (1..N) Relation : Lecteurs -------- Emprunter ----→ Livres (0..N à 1..N)

Exercice 2 : Requête SQL

Énoncé : Écrire la requête pour obtenir tous les clients qui ont commandé plus de 5 fois

Solution :
SELECT C.Nom, COUNT(*) as Nombre_Commandes FROM Clients C JOIN Commandes CMD ON C.Num_Client = CMD.Num_Client GROUP BY C.Num_Client HAVING COUNT(*) > 5;

Exercice 3 : Créer une table

Énoncé : Créer une table Produits avec colonnes : ID, Nom, Prix, Stock

Solution :
CREATE TABLE Produits ( ID INT PRIMARY KEY AUTO_INCREMENT, Nom VARCHAR(100) NOT NULL, Prix DECIMAL(10,2), Stock INT DEFAULT 0 );

Exercice 4 : Modification (UPDATE)

Énoncé : Augmenter le prix de tous les produits de 10%

Solution :
UPDATE Produits SET Prix = Prix * 1.10;

Exercice 5 : Suppression (DELETE)

Énoncé : Supprimer les produits en rupture de stock

Solution :
DELETE FROM Produits WHERE Stock = 0;
