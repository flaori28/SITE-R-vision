SLAM - Concepts POO et Design Pattern

Classe et Objet

Classe : Modèle (blueprint) qui définit les propriétés (attributs) et comportements (méthodes) d'un type d'objet.
Objet : Instance d'une classe créée en mémoire avec des valeurs spécifiques.

Exemple : Classe Compte Bancaire

class CompteBancaire { private $solde = 0; private $titulaire; public function __construct($titulaire, $solde_initial) { $this->titulaire = $titulaire; $this->solde = $solde_initial; } public function deposer($montant) { $this->solde += $montant; return "Dépôt de $montant effectué"; } public function retirer($montant) { if ($montant <= $this->solde) { $this->solde -= $montant; return "Retrait de $montant effectué"; } return "Solde insuffisant"; } public function getSolde() { return $this->solde; } } // Instanciation $compte = new CompteBancaire("Jean Dupont", 1000); echo $compte->deposer(500); echo "Solde: " . $compte->getSolde();

Encapsulation

Encapsulation : Cachage des détails internes, exposition d'une interface publique.
public : Accessible partout
private : Accessible uniquement dans la classe
protected : Accessible dans la classe et ses sous-classes

Getters et Setters

class Personne { private $nom; public function setNom($nom) { if (strlen($nom) > 0) { $this->nom = $nom; } } public function getNom() { return $this->nom; } } $p = new Personne(); $p->setNom("Alice"); echo $p->getNom(); // Alice

Héritage

Héritage : Une classe fille hérite des propriétés et méthodes d'une classe mère (parent).
class CompteCourant extends CompteBancaire { private $decouverthauteur = 500; public function retirer($montant) { $limite = $this->getSolde() + $this->decouverthauteur; if ($montant <= $limite) { // Appeler la méthode parente return parent::retirer($montant); } return "Dépassement du découvert autorisé"; } } $compte = new CompteCourant("Alice", 200); echo $compte->retirer(600); // OK (200 + 500 découvert)

Redéfinition (Override)

Une classe fille peut redéfinir une méthode de sa classe mère pour adapter le comportement.

Polymorphisme

Polymorphisme : Capacité d'une méthode à avoir plusieurs implémentations selon la classe.
interface Animal { public function crier(); } class Chien implements Animal { public function crier() { return "Wouf wouf!"; } } class Chat implements Animal { public function crier() { return "Miaou!"; } } // Polymorphisme function faireParler(Animal $animal) { echo $animal->crier(); } faireParler(new Chien()); // Wouf wouf! faireParler(new Chat()); // Miaou!

Collections et Parcours

// Tableau d'objets $comptes = [ new CompteBancaire("Jean", 1000), new CompteBancaire("Marie", 2000), new CompteBancaire("Pierre", 1500) ]; // Parcours avec foreach foreach ($comptes as $compte) { echo $compte->getSolde() . " euros\n"; } // Filtrage et agrégation $solde_total = 0; foreach ($comptes as $compte) { $solde_total += $compte->getSolde(); } echo "Solde total: " . $solde_total;

Exercices

Exercice 1 : Modéliser une classe Voiture
Créez une classe Voiture avec attributs (marque, modèle, vitesse_max) et méthodes (accelerer, freiner, afficher_infos).
class Voiture { private $marque; private $modele; private $vitesse_max; private $vitesse_actuelle = 0; public function __construct($marque, $modele, $vitesse_max) { $this->marque = $marque; $this->modele = $modele; $this->vitesse_max = $vitesse_max; } public function accelerer($augmentation) { $this->vitesse_actuelle = min($this->vitesse_actuelle + $augmentation, $this->vitesse_max); } public function freiner($reduction) { $this->vitesse_actuelle = max($this->vitesse_actuelle - $reduction, 0); } public function afficher_infos() { echo "{$this->marque} {$this->modele} - Vitesse: {$this->vitesse_actuelle}/{$this->vitesse_max} km/h"; } }
Exercice 2 : Classe fille CompteEpargne
Créez une classe CompteEpargne héritant de CompteBancaire avec un taux d'intérêt annuel et méthode calculer_interets().
class CompteEpargne extends CompteBancaire { private $taux_interet = 0.02; // 2% par an public function calculer_interets() { $interets = $this->getSolde() * $this->taux_interet; $this->deposer($interets); return "Intérêts: $interets ajoutés"; } public function setTaux($taux) { $this->taux_interet = $taux; } } $epargne = new CompteEpargne("Jean", 10000); echo $epargne->calculer_interets(); // Intérêts: 200
Exercice 3 : Instanciation et Parcours
Créez 3 objets CompteBancaire et un tableau. Parcourez-les en affichant le solde moyen.
$comptes = [ new CompteBancaire("Alice", 1500), new CompteBancaire("Bob", 2500), new CompteBancaire("Charlie", 3000) ]; $somme = 0; foreach ($comptes as $c) { $somme += $c->getSolde(); } $moyenne = $somme / count($comptes); echo "Solde moyen: $moyenne";
Exercice 4 : Encapsulation
Modifiez CompteBancaire pour que $solde soit privé. Ajoutez une méthode privée pour valider le montant.
class CompteBancaire { private $solde = 0; private function validerMontant($montant) { return $montant > 0; } public function deposer($montant) { if ($this->validerMontant($montant)) { $this->solde += $montant; return true; } return false; } } // La méthode privée validerMontant n'est pas accessible de l'extérieur
Exercice 5 : Polymorphisme Interface
Créez une interface Vehicule avec méthode demarrer(). Implémentez-la dans Voiture et Moto.
interface Vehicule { public function demarrer(); } class Voiture implements Vehicule { public function demarrer() { return "Moteur de voiture démarré"; } } class Moto implements Vehicule { public function demarrer() { return "Moteur de moto démarré"; } } function faire_demarrer(Vehicule $v) { echo $v->demarrer(); }
