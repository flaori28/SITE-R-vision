1. Linux : Structure et Commandes

Linux est un système d'exploitation open-source basé sur UNIX. Il utilise une structure de répertoires hiérarchique.

Arborescence Linux : / (racine), /bin (binaires exécutables), /etc (fichiers configuration), /home (répertoires utilisateurs), /var (données variables), /tmp (fichiers temporaires), /opt (logiciels optionnels)
Commandes de base Linux : $ pwd # Répertoire courant $ ls -la # Liste détaillée des fichiers $ cd /chemin/dossier # Naviguer $ mkdir nouveau_doss # Créer un dossier $ touch fichier.txt # Créer un fichier $ cp source destination # Copier $ mv source destination # Déplacer/Renommer $ rm fichier.txt # Supprimer un fichier $ rmdir dossier # Supprimer un dossier vide $ cat fichier.txt # Afficher contenu $ grep "texte" file.txt # Rechercher dans un fichier $ sudo commande # Exécuter avec droits root $ useradd jean # Ajouter utilisateur $ passwd jean # Changer mot de passe $ who # Utilisateurs connectés

2. Gestion des Droits Unix (chmod)

Chaque fichier/dossier a 3 types de droits : lecture (r), écriture (w), exécution (x) pour 3 acteurs : propriétaire (u), groupe (g), autres (o).

Notation symbolique : chmod u+rwx,g+rx,o-rwx fichier.txt
u=utilisateur, g=groupe, o=autres, a=tous
+= ajouter, -= retirer, == définir
Notation octale : r=4, w=2, x=1
chmod 755 fichier → u:7(4+2+1), g:5(4+1), o:5(4+1)
755 = rwxr-xr-x (propriétaire lecture/écriture/exécution, groupe et autres lecture/exécution)
Exemples : chmod 755 script.sh # Propriétaire : rwx, Autres : r-x chmod 644 config.txt # Propriétaire : rw-, Autres : r-- chmod u+x fichier # Ajouter droit exécution propriétaire chmod g-w fichier # Retirer droit écriture groupe ls -l # Afficher droits : -rwxr-xr-x chmod 600 secret.txt # Propriétaire seul : rw-

3. Windows Server et Active Directory

Active Directory (AD) est l'annuaire centralisé pour gérer utilisateurs, ordinateurs et ressources en réseau Windows.

Active Directory : Service d'annuaire centralisé. Structure hiérarchique : Forêt → Arborescence → Domaines → Unités d'Organisation (OU) → Utilisateurs/Groupes/Ordinateurs
Domaine Windows : Ensemble d'ordinateurs et d'utilisateurs gérés centralement. Contrôleur de domaine (DC) = serveur AD. Utilisateur du domaine = connexion centralisée sur tous les PC du domaine.
GPO (Group Policy Object) : Règles de sécurité et configuration appliquées aux utilisateurs/ordinateurs du domaine. Restriction de software, obligation antivirus, lecteur réseau obligatoire, etc.
Commandes Windows Server/AD : net user nom_user * /add # Créer utilisateur local net localgroup groupe user /add # Ajouter user à groupe Get-ADUser -Filter * # Lister tous utilisateurs AD Set-ADUser -Identity user -Enabled $false # Désactiver compte Get-ADGroup -Filter * # Lister tous groupes New-GPO -Name "MaGPO" # Créer GPO dcdiag # Diagnostic contrôleur de domaine ipconfig /all # Afficher config TCP/IP

4. Permissions NTFS

NTFS (New Technology File System) est le système de fichiers Windows moderne avec permissions granulaires.

Permissions NTFS : Contrôle complet, Modification (lecture + écriture + exécution), Lecture seule, Écriture seule. Appliquées par utilisateur/groupe.
Héritage : Les fichiers héritent des permissions du dossier parent. Peut être désactivé pour des droits spécifiques.
Permissions NTFS Windows : Contrôle complet : Lecture, écriture, suppression, modification droits, prise de propriété Modification : Lecture + écriture + exécution Lecture : Voir fichiers, lancer exécutables Écriture : Créer fichiers, modifier contenu Exécution : Lancer exécutables, parcourir dossiers Pratique : Dossier partagé sur réseau → Partagé avec groupe "Ventes" : Lecture/Écriture → Partagé avec groupe "Direction" : Contrôle complet → Autres utilisateurs : Pas d'accès

Exercices Pratiques

Exercice 1 : Gestion des fichiers Linux
Vous avez un dossier /home/utilisateur/documents contenant des fichiers. Créez un sous-dossier "archives", copiez-y les fichiers de plus de 1 an, changez leur propriétaire et définissez les droits appropriés.
Correction :

$ cd /home/utilisateur/documents
$ mkdir archives
$ find . -maxdepth 1 -type f -mtime +365 -exec cp {} archives/ \;

Pour changer propriétaire (si admin) :
$ sudo chown utilisateur:utilisateur archives/*

Définir droits :
$ chmod 644 archives/* # rw-r--r-- (utilisateur rw-, autres r-)
$ chmod 755 archives # rwxr-xr-x pour dossier

Vérifier :
$ ls -la archives/
Exercice 2 : Permissions chmod
Un script bash /var/backup/backup.sh doit être exécutable uniquement par le propriétaire (root) et lisible par un utilisateur spécifique "backup_user". Définissez les permissions correctes.
Correction :

Propriétaire : root
Groupe : créer groupe "backup" et ajouter "backup_user"

$ sudo groupadd backup
$ sudo usermod -a -G backup backup_user
$ sudo chown root:backup /var/backup/backup.sh

Permissions :
$ sudo chmod 750 /var/backup/backup.sh
→ rwxr-x--- (propriétaire rwx, groupe rx, autres rien)

Vérification :
$ ls -l /var/backup/backup.sh
-rwxr-x--- 1 root backup
Exercice 3 : Active Directory et GPO
Une entreprise veut que tous les utilisateurs du domaine activent automatiquement le VPN au démarrage et que certains logiciels soient bloqués pour la comptabilité. Proposez une solution avec AD et GPO.
Correction :

Structure AD proposée :
Domaine "entreprise.local"
├── OU="Utilisateurs"
│ ├── OU="Comptabilité"
│ ├── OU="Ventes"
│ └── OU="IT"
└── OU="Ordinateurs"
├── OU="Comptabilité"
├── OU="Bureaux"

GPO 1 "VPN Automatique" (appliquée à Utilisateurs)
→ Script de connexion PowerShell qui lance VPN
→ Appliquée à tous utilisateurs du domaine

GPO 2 "Restriction Comptabilité" (appliquée à OU=Comptabilité)
→ Politique : Restriction de logiciels (Software Restriction Policy)
→ Bloquer exécutables non autorisés
→ Whitelist : Office, navigateur, logiciel comptabilité

Application :\n$ gpupdate /force # Forcer mise à jour GPO
Exercice 4 : Partage NTFS
Vous devez créer un partage réseau "Projets" avec les permissions suivantes : Ventes = Lecture/Écriture, Direction = Contrôle complet, Autres = Pas d'accès. Définissez les droits NTFS.
Correction :

1. Créer dossier C:\Partages\Projets

2. Propriétés → Onglet Sécurité → Modifier droits

3. Ajouter groupes et permissions NTFS :
- Groupe "Ventes" : Modification (Lecture + Écriture)
- Groupe "Direction" : Contrôle complet
- Utilisateurs authentifiés : Supprimer (non nécessaire)

4. Partage réseau : Propriétés → Partage avancé
- Nom du partage : Projets
- Permissions de partage : Tous = Lecture et Écriture (laisser NTFS faire le filtrage fin)

5. Héritage : S'assurer que l'héritage est activé pour propager droits aux fichiers créés

Résultat : "Ventes" peut lire/écrire les fichiers existants et nouveaux, "Direction" contrôle total, autres bloqués
Exercice 5 : Gestion Utilisateurs AD
Créez un utilisateur "jdupont" dans l'OU Ventes du domaine, définissez un mot de passe temporaire, forcez le changement à la première connexion, et ajoutez-le au groupe "Vendeurs".
Correction :

Via PowerShell sur contrôleur de domaine :

$password = ConvertTo-SecureString "Temp@123!" -AsPlainText -Force

New-ADUser -Name "jdupont" \
-GivenName "Jean" \
-Surname "Dupont" \
-Path "OU=Ventes,DC=entreprise,DC=local" \
-AccountPassword $password \
-Enabled $true \
-ChangePasswordAtLogon $true

Add-ADGroupMember -Identity "Vendeurs" -Members "jdupont"

Vérification :
Get-ADUser -Identity "jdupont" -Properties PasswordNotRequired
Get-ADGroupMember -Identity "Vendeurs"

Résultat : Utilisateur créé, mot de passe temporaire, changement obligatoire à première connexion, membre du groupe Vendeurs (hérite des permissions de groupe)
