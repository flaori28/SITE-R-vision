1. Les Entreprises et leur Environnement

📚 Qu'est-ce qu'une entreprise ?

Définition : Une entreprise est une organisation qui produit et/ou distribue des biens ou services.

Caractéristiques principales :

  • Personne morale ou physique
  • Activité économique
  • But lucratif (généralement)
  • Combien de facteurs de production

Environnement de l'entreprise :

PESTEL = Facteurs externes - Politique : Lois, impôts - Économique : Marché, concurrence - Social : Salaires, emploi - Technologique : Innovation - Environnemental : Écologie - Légal : Réglementations

2. Les Formes Juridiques

📚 Micro-entreprise (Auto-entrepreneur)

  • Capital : pas de minimum
  • Associés : 1 seul
  • Responsabilité : illimitée
  • Impôts : Forfait

📚 SARL (Société Anonyme Responsabilité Limitée)

  • Capital : 1 euro minimum
  • Associés : 2 à 100
  • Responsabilité : limitée au capital
  • Gestion : gérant(s)

📚 SA (Société Anonyme)

  • Capital : 37 500 euros minimum
  • Associés : 7 minimum
  • Responsabilité : limitée
  • Cotée en bourse possible

3. Les Ressources Humaines

📚 Fonction RH

Gère le personnel : recrutement, formation, paie, relations...

Processus RH :

1. Recrutement - Trouver les talents 2. Intégration - Onboarding 3. Formation - Développer compétences 4. Évaluation - Performance 5. Rémunération - Salaires 6. Licenciement - Départ

4. Aspects Juridiques Essentiels

📚 Contrat de Travail

  • CDI : Contrat à durée indéterminée
  • CDD : Contrat à durée déterminée
  • Stage : Formation professionnelle
  • Apprentissage : Formation + entreprise

📚 Obligations Légales

  • Immatriculation (SIREN, SIRET)
  • Comptabilité et bilan
  • Respect du code du travail
  • Déclaration de charges sociales
  • Respect de la confidentialité (RGPD)

Exercices Pratiques

Exercice 1 : Analyser une entreprise

Énoncé : Faire une analyse PESTEL d'une entreprise de votre choix

Solution (exemple Apple) :
Politique : Taxes, normes Économique : Concurrence (Samsung, Microsoft) Social : Salaires élevés, prestige Technologique : Innovation constante Environnemental : Réduction carbone Légal : Brevets, confidentialité

Exercice 2 : Choisir une forme juridique

Énoncé : Créer une startup IT avec 2 associés, capital initial 50 000€. Quelle forme juridique choisir ?

Solution :

SARL est idéale car :

  • Capital 1€ minimum OK
  • 2 associés possible
  • Responsabilité limitée
  • Gestion flexible
  • Moins de contraintes qu'une SA

Exercice 3 : Rédiger un contrat

Énoncé : Lister 5 éléments obligatoires d'un contrat de travail

Solution :
1. Identification des parties 2. Poste et fonctions 3. Lieu de travail 4. Durée (CDI/CDD) 5. Salaire et avantages 6. Date de prise de fonction 7. Conditions de fin de contrat

Exercice 4 : Calcul de salaire

Énoncé : Salaire brut 2000€. Charges sociales 22%. Salaire net = ?

Solution :
Salaire net = 2000 - (2000 * 0.22) = 2000 - 440 = 1560 euros

Exercice 5 : Cas pratique RSE

Énoncé : Comment une entreprise peut respecter la RSE (Responsabilité Sociale) ?

Solution :
  • Environnement : Réduire empreinte carbone
  • Social : Bien-être employés
  • Équitable : Salaires justes
  • Qualité : Produits durables
  • Communauté : Projets sociaux
