## 🚀 Déploiement sur GitHub Pages

### Option 1 : Upload via GitHub Web Interface (Recommandé)

1. **Va sur GitHub** : https://github.com/flaori28/r-vision-BTS-SIO1

2. **Upload les fichiers** :
   - Clique sur `Add file` → `Upload files`
   - Ou utilise le drag-drop sur la page

3. **Structure à uploader** :
   ```
   BTS-SIO-Revision/
   ├── index.html
   ├── css/
   │   └── style.css
   ├── js/
   │   └── main.js
   ├── pages/
   │   ├── bloc1/
   │   ├── slam/
   │   ├── sisr/
   │   ├── fondamentaux/
   │   └── transversal/
   ├── README.md
   ├── LICENSE
   └── .gitignore
   ```

4. **Activer GitHub Pages** :
   - Va sur **Settings** → **Pages**
   - Source: `main` branch / `/(root)`
   - Save

5. **Site en ligne** :
   - https://flaori28.github.io/r-vision-BTS-SIO1/

### Option 2 : Cloner et Pousser Localement

```powershell
# 1. Clone le repository
git clone https://github.com/flaori28/r-vision-BTS-SIO1.git
cd r-vision-BTS-SIO1

# 2. Copie les fichiers du projet
cp -r C:\BTS-SIO-Revision\* .

# 3. Ajoute et commit
git add .
git commit -m "Add BTS SIO revision platform - 15 pages, 75 exercises, 150 QCM"

# 4. Pousse (tu auras besoin de ton token)
git push origin main
```

### Option 3 : GitHub Desktop

1. Ouvre GitHub Desktop
2. **File** → **Clone repository**
3. Sélectionne `flaori28/r-vision-BTS-SIO1`
4. Copie les fichiers du projet dans le dossier cloné
5. **Commit to main**
6. **Push origin**
